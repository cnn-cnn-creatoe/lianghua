# v1.0.0 - 第一版量化研究终端

这是 `lianghua` 的第一版发布，目标是先完成一个可浏览、可扩展的量化研究前端，并把 A 股公开行情数据源和回测研究资料整理进项目。

## 本版内容

- 完成 A 股与加密货币分区的量化软件界面。
- 完成 A 股首页、行情列表、个股详情、题材/板块、资金流、龙虎榜、数据中心、回测测试等主要页面结构。
- 增加 A 股数据适配层，参考 `a-stock-data`、`adata`、`Ashare` 等项目的公开行情接口。
- 增加接口失败降级逻辑，数据不可用时保留示例数据，避免页面空白。
- 收录 `stock-quant`、`tdx2db`、TradingView 相关仓库和 UI 设计参考仓库源码快照。

## 不包含

- 不包含交易、下单、账户、登录、券商委托或实盘自动交易。
- 不包含投资建议或可直接实盘使用的交易信号。
