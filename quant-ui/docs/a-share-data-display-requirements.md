# A 股数据展示功能需求梳理

## 范围

当前阶段只做公开行情、题材、资金流、龙虎榜和回测研究入口展示，不做交易、下单、账户、登录和实盘委托。

## 可用接口映射

| 页面需求 | 参考接口 | 数据源 | 前端接入方式 |
| --- | --- | --- | --- |
| 首页主要指数和热门股票 | Tencent Finance quote | 腾讯财经 HTTP | 已通过 Vite 代理接入 |
| 行情列表 | Tencent Finance quote、Eastmoney push2 clist、adata 实时行情 | 腾讯财经 / 东方财富 / 新浪系接口参考 | 已接入并保留 fallback |
| 股票详情 | Tencent Finance quote | 腾讯财经 HTTP | 已接入现价、涨跌幅、成交额、换手、PE/PB、市值、涨跌停 |
| 板块与概念 | Baidu concept blocks | 百度股市通 PAE | 已作为行业、概念、地域归属参考 |
| 个股资金流 | Baidu fund flow | 百度股市通 PAE | 已作为主力、超大单、大单字段参考 |
| 强势股题材 | THS hot reason | 同花顺热点 | 已作为强势股和题材归因参考 |
| 龙虎榜 | Daily dragon tiger | 东方财富 datacenter | 已作为净买入、上榜原因参考 |
| K 线、盘口、逐笔、公告、新闻、行业横向 | mootdx / akshare / tdx2db | Python 或本地数据服务 | 需要后端服务封装后再接前端 |

## 数据适配层要求

- 所有接口统一走 `src/services/ashareData.ts`，页面不直接拼接第三方接口。
- 每个数据源使用统一的安全加载逻辑，返回 `live` 或 `fallback` 状态。
- 接口失败、空数据、非交易时段未更新时，页面继续显示示例数据并标记数据状态。
- 页面每 30 秒自动刷新一次，并保留手动刷新入口。

## 页面展示要求

- 总览：首页展示主要指数、实时核心指标、更新时间和接口状态。
- 股票详情：展示股票名称、代码、现价、涨跌幅、成交额、换手率、PE/PB、市值、涨跌停、概念标签、资金流。
- 行情列表：展示多只 A 股实时行情，点击股票后切换详情。
- 板块/题材：展示概念热力和强势股题材归因。
- 数据中心：展示接口清单、数据源状态和后续需要后端扩展的能力。
