# Lianghua 量化研究终端

`lianghua` 是一个面向 A 股和加密货币的量化研究前端。当前第一版聚焦“看数据、做分析、跑回测准备”，不包含交易、下单、账户、登录或实盘委托功能。

## v1.0.0 第一版范围

- A 股与加密货币分区：界面按市场拆分，便于后续分别接入行情、策略和回测能力。
- A 股行情展示：主要指数、热门股票、实时行情列表、个股详情、题材/板块、资金流、龙虎榜等模块。
- 数据适配层：通过 `quant-ui/src/services/ashareData.ts` 统一封装 A 股公开行情接口，接口异常时保留示例数据，避免页面空白。
- 回测测试入口：界面已预留回测测试、数据导入和策略研究模块，参考 `stock-quant`、`tdx2db`、`Ashare` 等项目继续扩展。
- 参考数据源快照：`reference-repos/` 收录本阶段调研和接入参考的开源项目源码快照，便于离线查看接口和实现方式。

## 数据源说明

当前前端只展示公开行情数据，不采集账户信息，不执行交易委托。A 股数据参考和适配来源包括：

- `a-stock-data`：腾讯财经、东方财富、同花顺、百度股市通等公开行情接口参考。
- `adata`：A 股实时行情、股票基础信息、市场数据接口参考。
- `Ashare`：轻量 A 股行情获取接口参考。
- `tdx2db`：通达信数据导入和本地数据落库参考。
- `stock-quant`：量化分析、回测测试和任务组织参考。
- TradingView 相关项目：用于后续 K 线、指标、脚本策略和跨市场展示能力扩展。

更完整的清单见 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。

## 重要边界

本项目当前版本仅用于量化研究、界面原型和公开数据展示，不构成投资建议。任何策略、信号、回测或指标结果都需要自行验证，不能直接作为实盘交易依据。
